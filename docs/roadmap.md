# Finalized 16-group roadmap

1. **Foundation — complete** — Node.js 24, TypeScript, MCP SDK v2, Zod v4, strict lint, Vitest, esbuild, docs, CI.
2. **MCP Protocol — complete** — stdio lifecycle, legacy/modern protocol interoperability, idempotent signal shutdown, EOF handling and real-client tests on Windows/Linux.
3. **Configuration & Trust — next** — trusted project roots and validated settings.
4. **Native Toolchain Discovery** — installed Gungnir CLI, compiler, SDK and CMake detection.
5. **Secure Process Runner** — allowlists, timeouts, cancellation, environment and output limits.
6. **Project Intelligence** — structured and legacy Gungnir profiles and module discovery.
7. **Compiler Validation** — syntax and semantic checks.
8. **IR & Diagnostics** — verify IR and normalize native diagnostics.
9. **Documentation Resources** — framework/version-aware grammar and guides.
10. **Documentation Search** — offline documentation index.
11. **MCP Prompts** — scaffolding, debugging and review workflows.
12. **Generation Planning** — previews, dependency and collision detection.
13. **Code Generation** — permission-gated native generators.
14. **Source Formatting** — check, preview, controlled apply.
15. **Build & Client Integration** — native compilation, Windows/Linux clients and npm package.
16. **Final Audit & Release** — end-to-end tests, security review, manual release.

No remote MCP service, arbitrary shell execution, live database mutations, automatic deployment or npm publication is authorized by this roadmap.
